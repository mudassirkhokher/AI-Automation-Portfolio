## Engineering Approach

I focus on building automation systems that are more than simple node-to-node workflows.

My projects commonly use:

* Modular workflow architecture
* Input validation
* Data normalization
* Structured AI outputs
* Deterministic business rules
* External API integrations
* Workflow state management
* Error and failure handling
* Separate processing stages
* Reusable workflow components

The goal is to combine **AI capabilities with reliable business automation** rather than relying on an LLM for every decision.
