These projects demonstrate practical experience with workflow orchestration, APIs, webhooks, AI models, data processing, lead management, communication automation, and human-in-the-loop processes.

## What These Projects Demonstrate

- Workflow design and orchestration with **n8n**
- Integration of AI models into business processes
- Webhook-based automation and API integration
- Data validation, transformation, and duplicate checking
- Email and communication automation
- Human-in-the-loop review and approval
- Lead generation, enrichment, and collection
- Document and invoice processing
- Early experimentation with voice agents and RAG systems

## Notes

- These are supporting and experimental projects; they are not all presented as production deployments.
- Some workflows may require external credentials, API keys, or service configuration before they can run.
- Credentials and secrets should be configured through n8n credentials or environment variables rather than stored in workflow files.
- The five main portfolio projects are documented separately in the repository root.
